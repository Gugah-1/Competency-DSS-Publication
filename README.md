# Competency Decision Support System

Repository ini berisi source code versi publikasi dari **Competency Decision Support System (Competency DSS)** yang dikembangkan selama pelaksanaan Kerja Praktik.

Sistem dikembangkan untuk mendukung pengelolaan kompetensi karyawan, proses assessment, pengelolaan training, monitoring competency gap, serta penyediaan informasi pendukung pengambilan keputusan.

## Main Components

- AI Assistant
- Competency Assessment Engine
- Authentication Service
- Employee Data Management
- Training Management
- Competency Workflow
- Bulk Import
- Backup Service
- Web-based User Interface

## Technology

- Python
- HTML
- CSS
- JavaScript

## Academic Publication Note

Repository ini merupakan **versi publikasi akademik** yang digunakan sebagai dokumentasi pendukung laporan Kerja Praktik.

Beberapa komponen operasional seperti database aktual, data karyawan, credential, file environment, serta informasi internal perusahaan tidak disertakan untuk menjaga keamanan dan kerahasiaan data.

## Repository Scope

This repository contains source code intended for academic documentation and review. It is not a complete production deployment package.
